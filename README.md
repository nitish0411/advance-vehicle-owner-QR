# 🚗 AutoGuard QR • Advanced Smart Vehicle QR & Emergency Contact System

> **Zero Personal Data on Sticker • Instant Wrong Parking Resolution • Masked VoIP Call • Multi-Contact Family Emergency SOS**

---

## 🌟 Key Features

### 1. 🛡️ 100% Privacy Protection (Zero Leakage on Sticker)
- **No phone number, full name, or home address is printed on the physical sticker.**
- Only a secure dynamic QR code and masked registration tag (e.g. `DL 01 ••• 4492`) are visible.

### 2. 📱 Interactive Scanner Portal (What Bystanders See)
- **1-Tap Quick Action Categories**:
  - 🚗 **Wrong / Blocked Parking**: Blocking Driveway Gate, No-Parking Zone, Double Parked, Blocking Emergency Exit.
  - ⚠️ **Vehicle Hazard & Safety Alert**: Headlights Left ON, Window Rolled Down / Open, Flat/Punctured Tyre, Alarm Ringing, Fluid Leakage.
  - 🚨 **Critical Emergency / Accident / Tow**: Hit & Scratched, Towing Underway, Medical / Child inside, Police Notice.
  - 💬 **Encrypted Anonymous Chat**: Direct two-way messaging without revealing phone numbers.
- **📍 Live GPS Location Attachment**: 1-tap browser geolocation sharing.
- **📷 Photo Evidence Attachment**: Scanners can snap and attach damage/parking photos.
- **📞 Masked VoIP Proxy Call Simulator**: In-browser call with simulated audio dialer & waveform.
- **📲 Pre-filled WhatsApp Safety Alert**: Instant formatted message dispatch.
- **🚨 SOS Emergency Multi-Broadcast**: Simultaneous alert to vehicle owner + **All Emergency Family Contacts** with siren audio and GPS coordinates.

### 3. 📊 Vehicle Owner Dashboard
- **Multi-Vehicle Management**: Register cars, SUVs, bikes with customizable quick notes & status (`Available`, `5-Min Errand`, `Valet`, `Do Not Disturb`).
- **Live Inbound Alerts Feed**: Real-time push stream with sound effects, photo attachments, and 1-tap quick replies (`🏃 Moving Car Now`, `✅ Thanks, Sorted!`, `📞 Calling Back`).
- **Emergency Family Circle**: Configure primary, spouse, parent, doctor emergency contacts with automated SOS rules.

### 4. 🎨 QR Sticker Print Studio
- Customizable high-res waterproof windshield sticker templates:
  - *Stealth Gold, Cyber Neon Cyan, Safety Amber, Crisp White, Carbon Red*
- Real-time QR generation with `qrcode.js`.
- **Direct High-Res PNG Download** and **1-Click Printable PDF / Paper Layout** (`@media print` optimized).

## 🚀 Getting Started

```bash
# Install dependencies
npm install

# Run Vite dev server
npm run dev

# Build for production
npm run build
```

Open your browser at `http://localhost:5173/`.
